# 888wiki 使用指南

[繁體中文專案首頁](../README.zh-TW.md) · [English](USAGE.md) · [安裝指南](INSTALLATION.zh-TW.md) · [功能詳情](FEATURES.zh-TW.md)

本指南介紹四種筆記格式、共用發布流程與 Seal 釋出控制。

## 1. 選擇筆記格式

開啟 **＋ 新增**，選擇 **Markdown**、**Block**、**Canvas** 或 **Whiteboard**。新筆記會固定使用建立時選擇的格式。連續文章適合 Markdown，可重排內容區塊適合 Block，關聯卡片適合 Canvas，自由繪圖則適合 Whiteboard。

## 2. 使用 Markdown 撰寫

建立 [Markdown 筆記](https://wiki.david888.com/new/markdown)。編輯器包含原始文字區與渲染預覽；可使用底欄調整版面與預覽裝置。工具列與匯入選單可快速插入 Markdown 結構、文件、圖片、音訊與連結。

Markdown 支援 GFM、數學公式、Mermaid／Graphviz 圖表、ECharts、引用與註腳、GitHub Alerts，以及擴充格式。使用 `Cmd/Ctrl+F` 搜尋，`Cmd/Ctrl+H` 搜尋取代。貼上或拖曳圖片時，可選擇上傳至 R2、本機 OCR 或表格辨識。

匯入音訊時可選逐字稿或智慧排版，逐字稿支援時間標記。工具列也能直接錄音；錄音前請確認所有參與者同意。

## 3. 建立 Block 文件

建立 [Block 筆記](https://wiki.david888.com/new/block)。點擊區塊左側的 **＋** 新增區塊，輸入 `/` 搜尋區塊類型，拖曳區塊把手調整順序。選取文字後可用浮動工具列設定格式。

可加入文字、標題、清單、表格、圖片、檔案、連結、YouTube、PDF、音訊、Mermaid、ECharts 與支援的嵌入內容。部分嵌入區塊可直接編輯。使用底欄匯出 PNG、HTML 或 PDF／列印；Markdown 匯出則在 Markdown 筆記中使用。

## 4. 使用 Canvas 整理關聯

建立 [Canvas 筆記](https://wiki.david888.com/new/canvas)。新 Canvas 會以空白畫布開始。

1. 點擊底部工具列的 **新增**。
2. 選擇思考卡片：Problem、Benefit、Solution、Cause、Criterion、Detriment、Question 或 Note。
3. 拖曳卡片調整位置。雙擊卡片編輯文字，拖曳尺寸控制點調整大小。
4. 從卡片邊緣的連接點建立連線。選取連線後可調整箭頭方向、線條樣式、粗細與顏色。
5. 使用復原／重做整理內容，使用置中功能查看全圖，並搜尋卡片文字。
6. 開啟檔案選單匯入或匯出 `.canvas`、輸出 PNG／SVG、從 Markdown WikiLink 產生關聯圖，或清空畫布；清空操作可復原。

新增選單也可加入圖片與檔案資源。圖片使用 R2；音訊、影片與文件附件使用已設定的 888box 上傳服務。發布後的 Canvas 會以唯讀互動圖呈現。

## 5. 使用 Whiteboard 手繪

建立 [Whiteboard 筆記](https://wiki.david888.com/new/whiteboard)。使用 Excalidraw 畫布工具繪圖、加入圖形和文字，整理視覺說明。自由草圖適合 Whiteboard；若內容以卡片與具名關係為主，請選 Canvas。

發布後的 Whiteboard 為唯讀。使用 Whiteboard 匯出功能輸出 PNG 或 SVG。

## 6. 發布與分享

使用底欄的 **分享** 控制發布筆記並建立分享網址。發布對話窗可設定發布、自動儲存與公開索引；也可設定閱讀／編輯密碼與段落註解。複製分享網址即可傳送已發布頁面。

讀者可將支援的筆記以書本或簡報方式開啟。書本章節格式、簡報分隔語法、匯出及其他閱讀工具請參閱完整功能詳情。

## 7. 使用 Seal 控制釋出

Seal 與閱讀／編輯密碼分開設定。在編輯器底欄點擊 **Seal**，選擇模式並填入參數，再按 **建立 Seal**。Seal 指示燈會顯示目前是否有生效規則。按 **解除 Seal** 可移除規則；設定立即生效。

| Seal 模式 | 效果 | 設定方式 |
| --- | --- | --- |
| **定時解鎖** | 訪客先看到倒數頁；到達指定時間後筆記才會公開。 | 選日期與時間，或使用 `+1h`、`+1d`、`+3d`、`+7d`、`+30d` 快捷鍵。 |
| **閱後即焚** | 達到瀏覽上限後銷毀筆記。 | 設定最大瀏覽次數。揭示確認步驟可降低連結預覽爬蟲提前消耗次數的機率。 |
| **亡者開關** | 作者定期簽到時維持封印；超過心跳間隔後自動釋出。 | 設定分鐘數，在 Seal 視窗發送 Pulse，或使用私有 Pulse 網址。儲存筆記也會更新心跳。 |
| **保留期限** | 分享連結在保留期限結束後到期並下架。 | 選擇 `10m`、`1h`、`1d`、`7d` 或 `30d`。 |

Seal 視窗提供 10 種情境範本，例如一次性密碼、預約發布、課程解鎖與緊急備援。範本只填入 Seal 設定，不會改寫筆記內容。建立前請再次確認模式、日期與限制。

## 8. 離線繼續寫作

離線工作區會先將草稿存入瀏覽器，再於網路恢復時同步待處理變更。可使用草稿清單與衝突處理功能比較本機和雲端版本，再決定保留方式。長期離線作業時，請定期匯出備份。
