# 888wiki

**以 Cloudflare Workers 為基礎的 AI 知識庫、寫作工作區與發布平台。**

使用 Markdown 或區塊編輯器撰寫內容，整理個人知識，並從自己的 Cloudflare 帳戶發布安全、易分享的頁面。

[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/tbdavid2019/888wiki)

[線上網站](https://wiki.david888.com) · [API](https://wiki.david888.com/api) · [Agent Skill](https://wiki.david888.com/.well-known/agent-skills/david888-wiki-publisher/SKILL.md)

## 你可以使用 888wiki

- **自由撰寫：** 使用 Markdown、BlockNote、畫布與白板編輯器，搭配多款主題、離線草稿和即時預覽。
- **AI 協作：** 格式整理、改寫、翻譯、音訊時間軸逐字稿，以及 MCP 相容的 AI Agent 工作流程。
- **掌握發布方式：** 公開或密碼保護分享、版本歷史、段落討論與簡報模式。
- **資料由自己管理：** 一鍵部署至自己的 Cloudflare Workers 帳戶，並建立 KV、D1、R2 資源與 D1 資料表。
